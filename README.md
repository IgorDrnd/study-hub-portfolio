# PortfolioHUB — Portfólio acadêmico de Igor Durando

Portfólio digital desenvolvido para apresentar minha trajetória acadêmica, meus interesses e meus projetos na área de Tecnologia da Informação. O projeto utiliza HTML, CSS, Git, GitHub e GitHub Pages.

## Acesse o projeto

- **Portfólio publicado:** https://igordrnd.github.io/study-hub-portfolio/
- **Repositório no GitHub:** https://github.com/IgorDrnd/study-hub-portfolio

## Objetivos

- Centralizar a apresentação dos projetos acadêmicos.
- Facilitar o acesso às informações e à documentação de cada projeto.
- Disponibilizar publicamente o portfólio pela internet.
- Utilizar o Git e o GitHub para versionar, armazenar e compartilhar o código.
- Utilizar ferramentas de inteligência artificial, como o Gemini, como apoio ao planejamento e à documentação, revisando as sugestões antes de aplicá-las.

## Tecnologias utilizadas

- HTML5

1. Abra a pasta do projeto no Visual Studio Code.
2. Abra o arquivo `index.html` em um navegador.
3. Opcionalmente, utilize a extensão Live Server para visualizar as alterações durante o desenvolvimento.

## Versionamento e publicação

O Git é utilizado para registrar as alterações realizadas no código. O GitHub armazena o repositório remoto e permite consultar o histórico de commits.

O site é publicado pelo GitHub Pages a partir da branch `master`, utilizando a pasta raiz (`/`).

Fluxo de trabalho adotado:

1. Realizar as alterações localmente.
2. Revisar os arquivos modificados.
3. Verificar as alterações com `git status` e `git diff`.
4. Registrar as alterações aprovadas com commits descritivos.
5. Enviar as alterações para o GitHub.
6. Verificar a publicação e o funcionamento do site.

## Segurança e controle de acesso

Como o repositório é público, é importante:

- Não publicar senhas, tokens, chaves de API ou credenciais.
- Não armazenar dados pessoais ou informações privadas desnecessárias.
- Revisar as permissões de acesso ao repositório e às contas utilizadas.
- Ativar autenticação em dois fatores na conta GitHub, quando disponível.
- Manter credenciais fora dos arquivos versionados.
- Revisar as sugestões de ferramentas de IA antes de incorporá-las ao projeto.

O portfólio é destinado à apresentação pública de projetos e documentação. Informações que não devem ser públicas precisam permanecer fora do repositório.

## Testes e validação

Antes de considerar uma atualização concluída, verificar:

- Se o site abre corretamente.
- Se os links de navegação e contato funcionam.
- Se os projetos e suas documentações estão acessíveis.
- Se a versão publicada corresponde às alterações enviadas ao GitHub.
- Se não foram incluídas credenciais ou informações privadas.

Os testes devem ser realizados após cada atualização relevante, registrando problemas encontrados e as respectivas correções.
