# Study Hub

## Visão geral

Projeto de organização de materiais acadêmicos e acompanhamento da minha evolução durante a formação em Ciência da Computação.

## Objetivos

- Reunir resumos, exercícios e atividades por disciplina.
- Organizar projetos acadêmicos e pessoais.
- Registrar certificados e estudos de tecnologias.
- Criar um histórico que contribua para a construção do portfólio profissional.

## Organização

Os materiais são organizados por disciplina, projetos e temas de estudo, utilizando nomes de pastas simples e consistentes.

## Tecnologias

- HTML5
- CSS3
- Git e GitHub

## Observação

Este projeto faz parte do portfólio acadêmico e pode ser ampliado conforme novos estudos e projetos forem desenvolvidos.
