# NotifiCar

## Visão geral
Projeto acadêmico desenvolvido em equipe para facilitar a comunicação de ocorrências relacionadas a veículos e estacionamento, como luzes acesas, janelas abertas, vagas bloqueadas e pequenos danos.

## Tecnologias
- Flutter e Dart
- Firebase
- Supabase / PostgreSQL

## Objetivo
A proposta é ajudar usuários a comunicar situações que possam exigir a atenção do proprietário de um veículo ou de outras pessoas envolvidas.
